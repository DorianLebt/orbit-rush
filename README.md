# Orbit Rush

Rhythmus-Spiel im Browser: Song (MP3/WAV/M4A) reinziehen, das Spiel erkennt die Beats und baut daraus automatisch ein Level. Zwei Planeten kreisen umeinander – drück die Taste, wenn der Planet auf der nächsten Kachel landet.

- Tastenmodi: beliebig, F J, D F J K, S D F J K L
- Schwierigkeit: Leicht bis Extrem, plus Hardcore-Modus
- Läuft komplett lokal im Browser, keine Installation nötig

Starten: `index.html` im Browser öffnen.
